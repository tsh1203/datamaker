============================================================================================
  数据生成框架 v2.1.0  使用说明
============================================================================================

文件说明
--------
  main.cpp        主控程序（编译、生成数据、运行标程、可选对拍与计时）
  data.cpp        数据生成器（主要修改此处编写生成逻辑）
  std.cpp         标准程序（参考正确答案）
  user.cpp        （可选）待测试的用户程序
  function.hpp    工具函数库（提供大量常用生成函数）
  data.txt        测试数据规模与变量范围配置文件
  help.txt        本文件
  README.md       GitHub 仓库首页说明

============================================================================================
  快速开始
============================================================================================

1. 编辑 data.txt，配置不同规模的测试组
2. 在 data.cpp 的标注区域编写数据生成逻辑
3. 编写或修改 std.cpp 作为标准答案
4. 编译并运行：

     g++ -O2 -o main.exe main.cpp
     ./main.exe                 # Linux / macOS
     main.exe                   # Windows

============================================================================================
  data.txt 格式（推荐新格式）
============================================================================================

• # 开头为注释，空行忽略
• 必须以 "problem <题目名>" 开头
• 使用 group ... end 结构定义测试组
• 每个 group 内必须包含 count（该组生成数量）

示例（price 题目）：

  problem price

  # 小数据：t 多、范围小
  group
    count  10
    t  1       50
    l  1       1000000
    r  1       1000000
  end

  # 大数据：极限范围
  group
    count  3
    t  1          5
    l  300000     1000000000
    r  300000     1000000000
  end

注意：
- 左界 > 右界时会自动交换并给出警告
- 变量名可自由命名，顺序自动记录
- 支持多个 group，可分别生成不同难度数据

============================================================================================
  data.cpp 使用说明
============================================================================================

在 data.cpp 中找到以下区域编写生成逻辑：

  // ======================================================
  //  ↓↓↓ 在这里编写数据生成逻辑 ↓↓↓
  // ======================================================

可用工具：

  vv["变量名"]        当前组该变量的随机值
  v_rd("变量名")      临时生成一个该变量范围内的随机值（每次不同）
  v["变量名"].first   变量左界
  v["变量名"].second  变量右界

示例：

  cout << vv["t"] << endl;
  for (int q = 1; q <= vv["t"]; ++q) {
      int l = v_rd("l"), r = v_rd("r");
      if (l > r) swap(l, r);
      cout << l << " " << r << endl;
  }

============================================================================================
  主程序运行模式（main.cpp）
============================================================================================

  main.exe                          普通模式：生成数据 + 标程答案
  main.exe --check                  对拍模式（std.cpp vs user.cpp）
  main.exe --check --user sol.cpp   指定对拍用户程序
  main.exe --time                   计时模式（显示每组耗时）
  main.exe --check --time           对拍 + 计时（推荐用于复杂度验证）

============================================================================================
  function.hpp 常用函数速查（完整版）
============================================================================================

1. 随机数与打乱
   rd(l, r)                          [l,r] 随机 long long 整数（最常用）
   rd_double(l, r)                   [l,r] 随机 double
   rd_bool(p=0.5)                    概率返回 true
   shuffle_vec(v)                    随机打乱 vector
   rd_permutation(n)                 [1..n] 随机排列
   rd_string(len, 'a','z')           随机字符串
   rd_string_from(len, charset)      自定义字符集随机字符串

2. 树与图生成
   BuildTree(n)                                    随机无权树
   BuildTree(n, shape, strength)                   指定形状（RANDOM/CHAIN/FLOWER/BALANCED）
   BuildWeightedTree(n, minW, maxW)                带权随机树
   BuildGraph(n, m, opt)                           通用随机图（支持有向/连通/带权）
   BuildDAG(n, m)                                  随机 DAG（保证无环）

3. 并查集
   DSU dsu(n);
   dsu.find(x) / dsu.unite(x,y) / dsu.connected(x,y)

4. 序列与向量
   GenSeq(count, lo, hi, distinct=false, sorted=false)   一维随机序列
   GenVectors(...)                                       多维向量

5. 多边形生成
   GenConvexPolygon(n, radius=1000.0)     随机凸多边形
   GenSimplePolygon(n, radius=1000.0, perturbation=0.3)  随机简单多边形
   PolyArea(poly) / PolyPerimeter(poly) / PolyContains(...)

6. 字符串与文本
   rd_word()                    随机英文单词
   rd_sentence(words=8)         随机句子
   rd_paragraph(...)            随机段落

7. 输出辅助
   print_vec(v, sep=" ")        输出 vector
   print_edges(edges)           输出边列表（支持多种格式）
   PrintVectors(flat, D)        输出多维向量
   PrintPoly(poly, prec=6)      输出多边形

8. 文件工具
   st(name, n)                  返回 "data/题目名/题目名N"
   fileExists(path)
   createDirectory(path)

9. data.cpp 常用
   vv["变量名"]                 当前组随机值
   v_rd("变量名")               临时随机值
   v["变量名"].first/.second    变量范围

============================================================================================
  常见问题与建议
============================================================================================

• 大范围随机推荐使用 rd(l, r)
• 生成树图时优先使用 BuildTree / BuildGraph
• 对拍失败时会自动列出失败用例编号
• 想测试时间复杂度请使用 --check --time
• 数据生成逻辑越简单越好，复杂逻辑可组合使用 function.hpp 中的函数
