文件说明
--------
  main.cpp        主控程序（编译、生成数据、运行标程、可选对拍）
  data.cpp        数据生成器（修改底部标注区域来自定义生成逻辑）
  std.cpp         标准程序（参考正确答案）
  user.cpp        （可选）待测试的用户程序
  function.hpp    工具函数库（提供大量常用生成函数）
  data.txt        数据规模/变量范围配置文件
  help.txt        本文件
  README.md       项目快速入门说明

============================================================================================
  快速开始
============================================================================================

1. 编辑 data.txt，定义测试数据的规模和变量范围
2. 修改 data.cpp 中的“数据生成逻辑”部分
3. （可选）编写 std.cpp 作为标准答案
4. 编译运行主程序：

     g++ -O2 -o main.exe main.cpp
     ./main.exe                 # Linux/macOS
     main.exe                   # Windows

============================================================================================
  data.txt 格式（推荐新格式）
============================================================================================

• 以 # 开头的行为注释，空行会被忽略
• 必须以 "problem <题目名>" 开头
• 使用 group ... end 块定义不同规模的测试组
• 每个 group 内必须有 count（生成该组数据的数量）
• 变量行格式：变量名  左界  右界

完整示例（price 题目）：

  problem price

  # 小数据：t 较多，l,r 范围较小
  group
    count  10
    t  1       50
    l  1       1000000
    r  1       1000000
  end

  # 大数据：t 较少，l,r 为极限范围
  group
    count  3
    t  1          5
    l  300000     1000000000
    r  300000     1000000000
  end

注意事项：
- 左界 > 右界时会自动交换并输出警告
- 变量名可随意命名（建议简洁有意义）
- 支持多个 group，可分别生成不同难度/规模的数据

============================================================================================
  data.cpp 使用说明
============================================================================================

在 `data.cpp` 中找到以下标注区域：

  // ======================================================
  //  ↓↓↓ 在这里编写数据生成逻辑 ↓↓↓
  // ======================================================

可用全局变量与函数：

  vv["变量名"]        当前组该变量的随机值（已生成）
  v_rd("变量名")      临时生成一个该变量范围内的随机值（每次调用不同）
  v["变量名"].first   变量的左界
  v["变量名"].second  变量的右界

示例（多组询问，每组输出 l r）：

  cout << vv["t"] << endl;
  for (int q = 1; q <= vv["t"]; ++q) {
      int l = v_rd("l"), r = v_rd("r");
      if (l > r) swap(l, r);
      cout << l << " " << r << endl;
  }

============================================================================================
  主程序运行模式（main.cpp）
============================================================================================

  main.exe                          普通模式：生成数据 + 标程答案
  main.exe --check                  对拍模式：std.cpp vs user.cpp
  main.exe --check --user sol.cpp   指定对拍的用户程序
  main.exe --time                   计时模式（显示每组标程耗时）
  main.exe --check --time           对拍 + 计时（推荐）

============================================================================================
  function.hpp 常用函数速查
============================================================================================

随机数相关：
  rd(l, r)                    [l,r] 随机整数（mt19937_64）
  rd_double(l, r)             [l,r] 随机浮点数
  rd_bool(p=0.5)              概率 p 为 true
  rd_permutation(n)           [1..n] 随机排列
  rd_string(len, 'a','z')     随机字符串

图与树：
  BuildTree(n)                            随机树
  BuildWeightedTree(n, minW, maxW)        带权随机树
  BuildGraph(n, m, options)               随机图
  BuildDAG(n, m)                          随机 DAG
  DSU dsu(n);                             并查集

其他实用功能：
  GenSeq(count, lo, hi, distinct)         随机序列
  GenConvexPolygon(n)                     随机凸多边形
  rd_sentence(words)                      随机英文句子
  print_vec(v) / print_edges(edges)       输出辅助

详见 function.hpp 文件内的注释。

============================================================================================
  常见问题与建议
============================================================================================

Q: 如何生成更复杂的输入格式？
A: 在 data.cpp 的生成逻辑中自由使用 cout 输出，结合 vv[] 和 v_rd() 即可。

Q: 数据生成太慢？
A: 优先使用 v_rd() 而非每次新建分布；大范围随机已优化。

Q: 对拍时发现 WA/RE？
A: 使用 --check 模式，程序会自动列出失败的用例编号。

Q: 想测试时间复杂度？
A: 使用 main.exe --check --time
