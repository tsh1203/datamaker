============================================================================================
  数据生成框架 v2.1.0  使用说明
============================================================================================

文件说明
--------
  main.cpp      主控程序（编译、生成数据、运行标程、可选对拍）
  data.cpp      数据生成器（修改底部标注区域来自定义生成逻辑）
  std.cpp       标准程序（参考答案）
  function.hpp  工具函数库
  data.txt      数据规模/变量范围配置文件
  help.txt      本文件

============================================================================================
  快速开始
============================================================================================

1. 配置 data.txt（见下方）
2. 修改 data.cpp 中"数据生成逻辑"部分
3. 编译运行：
     g++ -O2 -o main.exe main.cpp
     main.exe

============================================================================================
  data.txt 格式
============================================================================================

• # 开头为注释，空行忽略
• 关键字：problem / group / count / end
• 变量行格式：<变量名>  <左界>  <右界>
• 变量名随意，不限个数，顺序即为 varOrder

模板：

  problem <题目名>

  # 可以写注释说明这是什么规模
  group
    count  <组数>
    <变量名>  <左界>  <右界>
    <变量名>  <左界>  <右界>
    ...
  end

  group
    ...
  end

示例（price 题）：

  problem price

  # 小数据：t 多、范围小
  group
    count  10
    t  1       50
    l  1       1000000
    r  1       1000000
  end

  # 大数据：极限范围
  group
    count  3
    t  1          5
    l  300000     1000000000
    r  300000     1000000000
  end

对比旧格式（v2.0.0 及之前）：

  旧：price\n2 3\n10 t 1 50 l 1 1000000 r 1 1000000\n...
  新：可读、可注释、变量数自动推断、左>右自动交换并警告

============================================================================================
  data.cpp 使用
============================================================================================

在标注区域内可使用：

  vv["变量名"]        本组该变量的随机值（整数）
  v_rd("变量名")      临时再取一次该变量范围内的随机值
  v["变量名"].first   变量左界
  v["变量名"].second  变量右界

生成逻辑示例（多组询问，每组 l r）：

  cout << vv["t"] << endl;
  for (int q = 1; q <= vv["t"]; ++q) {
      int l = v_rd("l"), r = v_rd("r");
      if (l > r) swap(l, r);
      cout << l << " " << r << endl;
  }

============================================================================================
  主程序运行模式（main.cpp）
============================================================================================

  main.exe                         普通模式：生成数据 + 标程答案
  main.exe --check                 对拍模式：标程 vs user.cpp
  main.exe --check --user sol.cpp  指定对拍用户程序
  main.exe --time                  计时模式（标程每组耗时）
  main.exe --check --time          组合使用

============================================================================================
  function.hpp 速查
============================================================================================

随机数
  rd(l, r)              [l,r] 随机整数（mt19937_64）
  rd_double(l, r)       [l,r] 随机浮点数
  rd_bool(p=0.5)        随机布尔
  shuffle_vec(v)        随机打乱 vector
  rd_permutation(n)     [1..n] 随机排列
  rd_string(len,lo,hi)  随机字符串（默认小写字母）

图 / 树
  BuildTree(n)                   随机无权树
  BuildWeightedTree(n,min,max)   随机带权树（返回 tuple<u,v,w>）
  BuildGraph(n, m)               随机连通图
  BuildDAG(n, m)                 随机 DAG

并查集
  DSU dsu(n);
  dsu.find(x)  /  dsu.unite(x,y)  /  dsu.connected(x,y)

输出
  print_vec(v, sep)    输出 vector
  print_edges(edges)   输出边列表（无权/带权均支持）

文件
  st(name, n)          → "data/name/nameN"
  fileExists(path)     文件是否存在
  createDirectory(p)   创建目录（跨平台）
