# datamaker v2.2.0

一个高效、灵活、跨平台的竞赛题目**测试数据批量生成工具**，支持 Windows / Linux / macOS。

### 核心特性

- 清晰易用的 `data.txt` 配置格式（支持多组、注释）
- 高质量随机数（`mt19937_64`）
- 丰富生成工具：随机树、图、DAG、凸多边形、序列等
- 一键生成数据 + 标准答案
- 支持**对拍**与**时间统计**

### 快速开始

```bash
# 1. 编译
g++ -O2 -o main.exe main.cpp

# 2. 生成数据和标程答案
./main.exe

# 3. 对拍（推荐）
./main.exe --check

# 4. 对拍 + 计时
./main.exe --check --time
```

测试数据将生成在 `data/<题目名>/` 目录下。

### 文件结构

| 文件           | 说明                          |
|----------------|-------------------------------|
| `main.cpp`     | 主控程序（生成、对拍、计时） |
| `data.cpp`     | 数据生成器（主要修改此处）    |
| `std.cpp`      | 标准程序（参考答案）          |
| `data.txt`     | 测试数据规模配置              |
| `function.hpp` | 工具函数库                    |
| `help.txt`     | 详细使用说明                  |

### 使用流程

1. 配置 `data.txt`（定义不同规模的测试组）
2. 在 `data.cpp` 中编写数据生成逻辑
3. 编写 `std.cpp` 作为正确答案
4. 运行 `main.exe` 生成数据

### 适用场景

- OI / ACM / 算法竞赛出题
- 批量生成强随机测试数据
- 验证程序正确性与时间复杂度
